📖 Spreadsheet Tools Guideline & Help

⚡ Bulk Lead List Clean

Automatically verifies large email lists using all 7 Reoon accounts in parallel:

  • Divides all unverified emails across available Reoon accounts to maximize daily verification speed.
  • Uses Daily Credits Only: Consumes free daily balances first to protect paid instant credits.
  • Non-Blocking: Safe to close the spreadsheet once started. Background triggers poll and write results every 1 minute automatically.
  • Activity Logging: Every run is logged to the info tab with User Email, Function, Sheet, Task ID, API Account, Date, Total emails, and Status.
  • Auto Recovery: If task metadata is lost but the sheet has "Pending..." rows, the tool scans the info tab to recover active task IDs and resume verification.
  • Check Pending Results: Use this button to manually poll all active tasks and write results immediately.
✉️ Verify Account Emails
  • Access Restricted: This submenu is locked for all accounts. Only the sheet administrator is authorized to use individual account email verifications.
  • When run, it submits a bulk verification task for the selected account tab and immediately returns — no waiting required.
  • Results appear automatically within 1–5 minutes via a background trigger — you can continue working while it runs.
  • A confirmation alert shows the Task ID and email count upon submission.
  • Activity is logged to the info tab for monitoring.
🧹 Clean Decision Makers

Filters sheet rows to keep only target decision makers per company:

  • Requires Title / Job Title and Company / Company Name columns (case-insensitive).
  • Verification Priority: If a status column exists, deliverable emails (Safe → Role Account → Catch All) are prioritized automatically.
  • Title Keyword Fallback: If the keywords box is empty, it uses 29 pre-defined default titles (CEO, VP, Director, Owner, Founder, etc.). Custom keywords replace defaults entirely.
  • Supports filtering by Industry, Country, Seniority, and Department.
  • Outputs results to a new "Cleaned — [Sheet Name]" tab, keeping original data untouched.
  • Run is logged to the info tab with total rows kept.
🤖 Company Names Cleaner (GPT-Powered)

Cleans generic words and suffixes from company names to extract core brand names:

  • Uses OpenAI GPT API to remove locations, legal suffixes (LLC, Inc, GmbH), URLs, and generic business terms.
  • Start Cleaning: Duplicates the active sheet to a new tab named "[your email], the company name cleaning", adds a "Clean Company Name" column, and begins processing in batches of 100 rows per run.
  • Auto-Reschedule: Automatically reschedules itself every 1 minute until all rows are completed — no timeout errors.
  • Check Progress: Displays percentage done, last processed row, and remaining empty cells.
  • Reset Progress: Clears process markers to start fresh.
  • Safe Writes: Skips rows that already have a cleaned name to prevent overwrites.
  • Start event is logged to the info tab with total row count.
📊 Info Tab — Activity Log

The info tab is an automatic activity log that records every automation run:

  • Columns tracked: User Email · Function · Sheet · Task ID · API Account · Date · Task Name · Status · Total · Progress · Action
  • All automations log here: Lead List Clean, Verify Emails, Decision Maker Filter, and Company Name Cleaner.
  • Misuse Monitoring: Admins can review who ran which tool, on which sheet, and how many rows were processed — and when.
  • The info tab is created automatically on first use and migrates itself if the column schema changes.
  • Do not delete or rename the info tab — it is required for Auto Recovery of pending verification tasks.
